# 1 Minuto de Luz

Portal estático de desafios recreativos e descobertas úteis.

## Funcionalidades
- Página responsiva com fotografias editoriais, cores suaves e navegação por âncoras.
- Três desafios interativos com cinco perguntas cada.
- Resultados recreativos ou pontuação, barra de progresso e compartilhamento.
- Vitrine editorial de achadinhos, ainda sem produtos comerciais nem preços não verificados.

## Rodar localmente
Abra `index.html` no navegador. Nenhum build ou banco de dados é necessário.

## Hospedar
Conecte este repositório ao Netlify ou Cloudflare Pages.
- Branch: `main`
- Build command: deixar vazio
- Publish directory: `.` (raiz)

Antes de trocar o DNS do domínio, valide a URL de pré-visualização.

## Ética e privacidade
Não inclua dados do antigo bot WhatsApp, arquivos de clientes, logs ou credenciais.
Testes de perfil são recreativos, não diagnósticos.
Links de afiliados deverão ser identificados; preços e disponibilidade precisam ser verificados antes da publicação.
